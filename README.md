# To-Do List

Простое веб-приложение для создания и управления списком задач.

## Демо

[Открыть приложение](https://borispsychologi-cloud.github.io/todo-list/)

## Исходный код

[GitHub Repository](https://github.com/borispsychologi-cloud/todo-list)

## Функциональность

- Добавление новых задач.
- Отметка задач как выполненных.
- Удаление задач.
- Сохранение задач после обновления страницы с помощью localStorage.
- Адаптивное отображение для мобильных устройств.

## Технологии

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages

## Использование AI

В процессе разработки использовался ChatGPT (OpenAI):

- Помощь в написании и разборе кода.
- Поэтапная реализация функциональности.
- Объяснение логики JavaScript и CSS.
- Поиск и исправление ошибок.
- Тестирование основных сценариев работы приложения.

## Запуск локально

Скачайте репозиторий и откройте файл `index.html` в браузере.
